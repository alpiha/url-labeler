      Environments

      One address per environment, e.g. dr.dk. Use * for a part that stays the same, like *.example.com. Everything after the address (path, query, #) is kept. Add a path to the address if your environments differ by path, e.g. example.com/staging.

      Turn this off to always go to the address as written, e.g. a site's front page.
