# URL Labeler – Privacy Policy

_Last updated: 27 October 2026_

URL Labeler does not collect, store, sell or share any personal data.

## What the extension uses

- **Page addresses (URLs):** The URL of each open tab is compared with the label rules you create. This happens only inside your browser. URLs are never saved, logged or sent anywhere.
- **Your label rules:** The rules you create are saved in your browser's local extension storage (`chrome.storage.local`) on your own computer. They are not synced or uploaded.
- **Page content:** The extension does not read page content. On a matching page it only adds a label to the tab title or tab icon, or shows a small label on the page.

## What the extension does not do

- It does not send data to any server. It makes no network requests at all.
- It does not use analytics, tracking or advertising.
- It does not run remote code.
- It has no user accounts.

## Import and export

If you export your rules, a JSON file is saved to your computer. You decide whether to share that file with anyone.

## Removing your data

Uninstalling the extension removes all saved rules from your browser.

## Changes

If this policy changes, the updated version will be published at this address with a new date.
